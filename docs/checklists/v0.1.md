# v0.1 · გამოშვების ჩეკლისტი

[#47](https://github.com/tshamugia/jerry/issues/47)-ის ხელით შესამოწმებელი პუნქტები: რასაც ტესტი ვერ ამოწმებს (ნამდვილი თაგვი და კლავიატურა, სხვა პროგრამები, ნამდვილი დისკები, თვალი). თითო პუნქტი ერთხელ მოწმდება, ნამდვილ ფუნქციაზე.

სტატუსები: ⬜ ღიაა · ✅ დადასტურებულია (ვინ ან სად, თარიღით) · ❌ ხარვეზია (issue-ს ნომრით) · ⏭ გადატანილია (სად).

`შედეგი` სვეტში ჩანაწერი `#38` ნიშნავს, რომ პუნქტი იმ issue-ზე მუშაობისას მომხმარებელმა ხელით დაადასტურა. ბრძანებები PowerShell-შია.

## 0. მომზადება

- **კომპიუტერი:** Lenovo 83DN, Intel Core Ultra 9 185H, 32 GB, NVMe SSD, hybrid GPU (Intel Arc + NVIDIA RTX 4060 Laptop), კვებაზე.
- **სატესტო Jerry #46-იდან:** `0.1.0-rc.91` ნამდვილი ვერსიიდან ვერასოდეს განახლდება (სატესტო გასაღები, localhost endpoint). ✅ 08.11.2026: `%LOCALAPPDATA%\Programs\Jerry` არ არსებობს, Add/Remove Programs-ში Jerry არ ჩანს.
- **Build:** ხელით შემოწმება ინსტალერიდან დაყენებულ Jerry-ზე ტარდება, არა dev build-ზე. 09.11.2026-დან ამ კომპიუტერზე დაყენებულია `0.1.0-rc.2` (§11).
- **სატესტო საქაღალდეები:**
  - `%TEMP%\jerry-synth\1000`, `10000`, `100000`: სინთეზური საქაღალდეები (`cargo bench -p jerry-core` ქმნის).
  - `%TEMP%\jerry-synth\ქართული სახელები`: 40 უჩვეულო სახელი, spike #18-იდან.
  - გრძელი გზა (§7): ქვემოთ მოცემული ბრძანება ქმნის MAX_PATH-ზე გრძელ გზას.

```powershell
$dir = "\\?\$env:TEMP\jerry-check\long"
1..8 | ForEach-Object { $dir += "\ძალიან_გრძელი_საქაღალდის_სახელი_ნაწილი_$_" }
[IO.Directory]::CreateDirectory($dir) | Out-Null
[IO.File]::WriteAllText("$dir\გრძელი გზის ფაილი.txt", "test")
$dir.Length - 4
```

## 11. განახლებები: ნამდვილი Release (#46)

#46-ში განახლება ორი ლოკალური ხელმოწერილი build-ით, ლოკალური სერვერიდან შემოწმდა. ნამდვილ tag-მდე ვერ შემოწმდება: `latest.json`, როგორც `release.yml` აქვეყნებს, ჩამოტვირთვა GitHub-იდან და ნამდვილი გასაღების ხელმოწერა. Pre-release-ს `/releases/latest` არასოდეს სთავაზობს, ამიტომ შემოწმება ასე ტარდება:
