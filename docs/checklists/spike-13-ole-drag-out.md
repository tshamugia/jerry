# Spike #13: OLE drag & drop Jerry-დან გარეთ · ხელით შემოწმება

მიზანი: ექვსივე პროგრამა ფაილს ისე იღებს, როგორც Explorer-იდან. ყოველ პუნქტზე შეადარე იგივე ფაილის Explorer-იდან გადათრევას.

## მომზადება

1. გაუშვი `target\release\jerry.exe` (worktree `spike-13-ole-drag-out`). Jerry აჩვენებს სატესტო საქაღალდეს `%TEMP%\jerry-spike-13`.
2. ფანჯარა სათაურის ზოლით გადაადგილდება, ✕ ხურავს. სამიზნე პროგრამის გვერდით დასაყენებლად მოსახერხებელია Win+← / Win+→.
3. AutoCAD-ისთვის ჩააგდე ნამდვილი DWG ამ საქაღალდეში (Explorer-ით) და Jerry-ში დააჭირე **Refresh**. სატესტო `ნახაზი — სართული 1.dwg` ყალბია: AutoCAD მას დაზიანებულად ჩათვლის, მაგრამ ესეც ამტკიცებს, რომ ფაილი მივიდა.
4. მონიშვნა: კლიკი, Ctrl+კლიკი რამდენიმეზე. მონიშნულზე დაჭერით და გადათრევით ყველა მონიშნული მიდის.
5. ყოველი გადათრევის შემდეგ Jerry ქვემოთ წერს შედეგს (Dropped: copy / move, Cancelled) და დროებს. ლოგი: `%TEMP%\jerry-spike-13.log`.

იმავე დისკზე (C:) Explorer-სა და Desktop-ზე ჩაგდება ნაგულისხმევად **გადაიტანს** ფაილს, როგორც Explorer-იდან. ის Jerry-ის სიიდან ქრება; **Refresh** სატესტო ფაილებს თავიდან ქმნის.
