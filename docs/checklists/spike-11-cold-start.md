2. ბრძანებები PowerShell-შია, repo-ს საქაღალდიდან branch `spike/11-cold-start`-ზე (მაგ. worktree `D:\03_GITHUB\jerry\.claude\worktrees\gallant-satoshi-e74c09`).

## 1. თეთრი ციმციმი (თვალით)

ყოველი გაშვებისას Jerry ჩნდება 1 000 ფაილის სიით და ~3 წამში თავისით იხურება. ჯერ ეს ორი ხაზი:

```powershell
$env:JERRY_SPIKE_REPORT = "$env:TEMP\jerry-spike-11\eye.json"; $env:JERRY_SPIKE_EXIT = "3000"
Remove-Item Env:JERRY_SPIKE_BG, Env:JERRY_SPIKE_SHOW -ErrorAction SilentlyContinue
```

შემდეგ თითო ვარიანტი: დააყენე ცვლადი (თუ აქვს) და გაუშვი `& "$env:TEMP\jerry-spike-11\jerry-v2.exe"`. ვარიანტებს შორის ისევ გაუშვი მეორე ხაზი (`Remove-Item ...`). თითოეული ორჯერ სცადე: ერთხელ 30 წამიანი უმოქმედობის შემდეგ, მეორედ მაშინვე.

| # | ცვლადი | მოსალოდნელი | შედეგი |
| --- | --- | --- | --- |
| 1 | არაფერი (spike-ის ვარიანტი) | ფანჯარა მუქია პირველივე მომენტიდან, თეთრი არცერთ კადრში. 30 წამის შემდეგ ფანჯარა ~1.5 წამით ცარიელი (მუქი) რჩება, მერე ჩნდება სია; მაშინვე გაშვებისას სია თითქმის ფანჯარასთან ერთად ჩნდება | |
| 2 | `$env:JERRY_SPIKE_BG = "0"` (როგორც ახლა `main`-ში) | ფანჯარა ჯერ თეთრია (30 წამის შემდეგ ~1.5 წამით), მერე მუქდება. ეს არის გამოსწორებული ციმციმი | |
| 3 | `$env:JERRY_SPIKE_SHOW = "early"` | ფანჯარა ჩნდება მყისიერად (მუქი, ცარიელი), სია მოგვიანებით, როგორც #1-ში | |

კითხვა: #1 თუ #3 გირჩევნია? #1-ში ფანჯარა ~0.45 წამზე ჩნდება, #3-ში ~0.04 წამზე. სია ორივეში ერთ დროს ჩნდება.

## 2. ცივი გაშვება (ერთი ბრძანება)

```powershell
powershell -ExecutionPolicy Bypass -File scripts\spike-11-cold.ps1
```

- გამოჩნდება UAC: დაეთანხმე. ფაილების ქეშის (standby list) გასუფთავებას ადმინისტრატორი სჭირდება. Jerry თავად შენი ჩვეულებრივი უფლებებით ეშვება.
- ~5 წუთი ნუ შეეხები მაუსს და კლავიატურას: ყოველი გაშვება ელოდება, რომ კომპიუტერი მშვიდად იყოს. Jerry 8-ჯერ გამოჩნდება და თავისით დაიხურება, 25 წამის შუალედით (NVIDIA-ს ამ დროში ჩაეძინება, როგორც ჩვეულებრივ გაშვებამდე).
- ქეშის გასუფთავების შემდეგ სხვა გახსნილი პროგრამები წამიერად შენელდება: ფაილებს თავიდან კითხულობენ. ეს უსაფრთხოა, RAMMap-ის "Empty Standby List"-ის ტოლფასია.
- ბოლოს იბეჭდება ცხრილი, შედეგი კი ინახება `%TEMP%\jerry-spike-11\out\cold.jsonl`-ში. საკმარისია მომწერო "მზადაა": ფაილს მე წავიკითხავ.
