# Spike #18: ქართული სახელები და shortcut-ები, ხელით შემოწმება

Build: `pnpm tauri build --debug --no-bundle` → `target\debug\jerry.exe` (branch `spike/18-georgian`). Jerry პირველ გაშვებაზე ქმნის საქაღალდეს `%TEMP%\jerry-synth\ქართული სახელები` (40 სახელი: მხედრული, შერეული, ნომრიანი, გრძელი, მთავრული, ხუცური, emoji, RTL, CJK, უხილავი სიმბოლოები, არავალიდური UTF-16) და ორივე პანელში აჩვენებს. მარჯვენა სვეტი («Georgian spike»): შრიფტის გადამრთველი, ფანჯრის native სათაური და ბოლო shortcut-ები (key და code).

ავტომატური შემოწმება (`node scripts/spike-18-check.mjs`, გაშვების ბრძანებები ფაილის თავშია) უკვე გავიდა: შრიფტები ზონებით, მოჭრილი გლიფები, რიგის სიმაღლე, დალაგება, ფილტრი, სინთეტიკური კლავიშები; screenshot-ები `docs/assets/spike-18/`-შია. აქ დარჩა ის, რასაც მხოლოდ თვალი და ნამდვილი კლავიატურა ამოწმებს.

თითოეულ პუნქტს ✅ / ❌ და მოკლე შენიშვნა.

## A. რენდერი (თვალით, 100 % და 125–150 % მასშტაბზე)

1. **სია:** ქართული სახელები სუფთაა, ასოები არ არის მოჭრილი ზემოდან ან ქვემოდან (ფ, ქ, ჭ, ღ, ყ, ჯ, ჰ), ლათინური და ქართული ერთ ხაზზე სწორად სხედან (`Project ბათუმი Tower B-3 rev.4.dwg`, `INV-2025-014 ინვოისი TSGroup.pdf`). ცარიელი კვადრატები (tofu) არსად ჩანს.
2. **გრძელი სახელები:** `ტექნიკური დავალება — …` და `ძალიან_გრძელი_სახელი_…` ბოლოში `…`-ით იჭრება, რიგი არ იზრდება.
3. **მთავრული და ხუცური:** `ᲜᲐᲮᲐᲖᲘ ᲡᲐᲑᲝᲚᲝᲝ.dwg`, `ႠႡႢ ⴀⴁⴂ ხუცური.txt`, `ჱ ჲ ჳ ჴ …` ჩანს ნორმალური ასოებით.
4. **უჩვეულო სახელები:** 📁 და 👨‍👩‍👧 ფერადია (ოჯახი ერთ ნიშნად), 🇬🇪 ჩანს როგორც «GE» (Windows-ს დროშის emoji არ აქვს, Explorer-შიც ასეა), `ა̈ ე́ ო̃`-ში ნიშნები ასოს თავზეა, არაბული/ებრაული ტექსტი რიგს არ არღვევს, CJK ჩანს, `უცნაური � სახელი.txt`-ში შუაში � ნიშანია.
5. **ტაბები:** `ქართული სახელები`, `ბათუმი 2026 · Tower B`, `ᲜᲐᲮᲐᲖᲔᲑᲘ` სუფთაა; გრძელი სახელები `…`-ით იჭრება და ტაბის სიმაღლე არ იცვლება.
6. **Breadcrumb:** ბოლო სეგმენტი `ქართული სახელები` თამამია (semibold) და სუფთა; მარჯვენა პანელში `… › ბათუმი 2026 › Tower B › 04_გაცემული`.
7. **Sidebar:** `ბათუმი 2026`, `ხელშეკრულებები` სხვა პუნქტების სიმაღლისაა.
8. **ფილტრის ველი:** Ctrl+F, აკრიფე ქართულად `ნახაზ`: ველში ტექსტი სუფთაა, სიაში რჩება ნახაზები და `ᲜᲐᲮᲐᲖᲘ ᲡᲐᲑᲝᲚᲝᲝ.dwg`, status bar-ში «Showing N of 40». Esc ასუფთავებს.
9. **შრიფტის შედარება:** მარჯვენა სვეტში «Segoe UI» და «Sylfaen»: Sylfaen-ით ქართული აშკარად სხვანაირია (უფრო მსხვილი, სხვა ფორმა); «Jerry»-ზე დაბრუნებისას ისევ Segoe UI-ის ქართულია.
10. **Taskbar და Alt+Tab:** Jerry-ს სათაური `ქართული სახელები — Jerry` სწორად ჩანს taskbar-ის hover preview-ში, Alt+Tab-ში და Task Manager-ში. მარჯვენა პანელზე კლიკი სათაურს `ბათუმი 2026 · Tower B — Jerry`-ზე ცვლის.

## B. Shortcut-ები ნამდვილ ქართულ განლაგებაზე (Georgian QWERTY)

Win+Space-ით ან Alt+Shift-ით გადართე ქართულზე (language bar-ში «KA»). ფოკუსი სიაზე (დააკლიკე რიგს), შემდეგ:

11. **Ctrl+C:** მარჯვენა სვეტში `Copy (Ctrl+C) · key "ც" · code KeyC`.
12. **Ctrl+V:** `Paste (Ctrl+V) · key "ვ" · code KeyV`.
13. **Ctrl+F:** ფილტრის ველი ფოკუსდება, `Filter (Ctrl+F) · key "ფ" · code KeyF`; WebView2-ის საკუთარი «Find» ზოლი არ ჩნდება.
14. **Ctrl+Shift+N:** `New folder (Ctrl+Shift+N) · key "N" · code KeyN`. თუ ენის გადართვა Ctrl+Shift-ზე გაქვს დაყენებული, შეამოწმე, რომ კომბინაცია ენას არ ცვლის და shortcut მაინც ირთვება.
15. იგივე 11–14 ინგლისურ განლაგებაზე: იგივე შედეგი, მხოლოდ key იქნება `c`, `v`, `f`, `N`.
16. **ფილტრის ველში** (ქართულ განლაგებაზე): Ctrl+C და Ctrl+V ტექსტს აკოპირებს და სვამს, მარჯვენა სვეტში ახალი ჩანაწერი არ ჩნდება. AltGr+C წერს `©`-ს, AltGr+E `ჱ`-ს.
17. ქართული ასოს უბრალო აკრეფა სიაზე ფოკუსით (Ctrl-ის გარეშე) არაფერს ირთავს.
